# Three Reminders, Zero Reminders

A tiny TypeScript program that delivers a one-line joke excusing a missed
deadline: three reminders were set, all three conspired to remind each other
instead of their owner — which is technically teamwork, just not mine.

Run `node main.ts` and it writes the line, exactly one line with no trailing
newline, to `/output/entry.txt`.
